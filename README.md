# VoltLift

Website for an electric forklift business: sales, service, rentals, batteries and spare parts, with a 3D forklift you can rotate, a savings calculator, AMC care plans and WhatsApp quotes.

**Live:** https://electric-forklift.vercel.app

![VoltLift hero, "Heavy lifting, zero emissions", beside an interactive 3D forklift](docs/screenshot.jpg)

![Animated demo: scrolling through the VoltLift site](docs/demo.gif)

## Built with

A single `index.html` with HTML, CSS, JavaScript and Three.js (from a CDN).

## Run it locally

Open `index.html` in a browser, or serve the folder with any static server.
